## Project Overview

This is a JavaScript library for logging to Graylog using the GELF (Graylog Extended Log Format) protocol. The library supports both UDP and TCP transport protocols and can output logs to console, Graylog, or both.

## Development Commands

- **Build TypeScript**: `npm run build` (compiles TypeScript to JavaScript)
- **Run tests**: `npm test` (uses Jest with TypeScript support)
- **Start the logger**: `npm start` (builds and runs with `--expose-gc` flag for garbage collection)
- **Development mode**: `npm run dev` (runs TypeScript directly with ts-node)

## Architecture

### Core Files

- **src/logger.ts**: Main logger implementation with TypeScript types and all core functionality
  - `createLogger()`: Factory function that returns logger instance with debug/info/warn/error/critical methods
  - Transport layer: UDP/TCP socket handling for sending logs to Graylog
  - Console output: Formatted local logging
  - GELF message formatting: Creates properly structured GELF messages
  
- **src/types.ts**: TypeScript type definitions for all interfaces and types
- **src/gelf-logger-config.ts**: Default configuration template with TypeScript types
- **src/index.ts**: Main export file for the package
- **dist/**: Compiled JavaScript output (generated by `npm run build`)

### Key Architecture Patterns

- **Configuration Hierarchy**: Environment variables override defaults, custom config overrides both
- **Async Remote IP Resolution**: Uses AWS CheckIP service to get public IP for log metadata
- **Transport Abstraction**: Single interface for UDP/TCP with protocol-specific implementations
- **Garbage Collection**: Explicit GC calls after logging operations when `--expose-gc` is used

### Configuration Options

The logger accepts configuration via environment variables or custom config object:
- `GRAYLOG_HOST`, `GRAYLOG_PORT`, `GRAYLOG_TRANSPORT` (udp/tcp)
- `GRAYLOG_APPLICATION_NAME`, `GRAYLOG_ENVIRONMENT`
- `GRAYLOG_OUTPUT` (local/remote/both)
- `GRAYLOG_MIN_LEVEL_LOCAL`, `GRAYLOG_MIN_LEVEL_REMOTE`

### TypeScript Features

- **Strict Type Safety**: Full TypeScript strict mode enabled
- **Interface Definitions**: Comprehensive types for configuration, log objects, and GELF messages
- **Generic Type Support**: Flexible logger configuration with type safety
- **Compile-time Validation**: Catch errors before runtime
